# 🐍 Python Basics — Programming Collection

Welcome to **Python Basics**, a collection of beginner-friendly Python programs designed to develop programming fundamentals, logical thinking, and problem-solving skills.

This repository contains three projects covering mathematical logic, number sequences, and basic program structure.

## 📂 Projects

### 1. Project 1 — Factorial

Learn how to calculate the factorial of a number using Python. This project helps you understand loops, conditional statements, and mathematical logic.

**Concepts Covered:** Loops, conditionals, and arithmetic operations.

🔗(https://github.com/ravikantsharma06/python_basics_25BCON2154.git)

### 2. Project 2 — Fibonacci Series

Explore the Fibonacci sequence, where each number is the sum of the two preceding numbers. This project helps build an understanding of loops, variables, and sequence generation.

**Concepts Covered:** Loops, variables, and number sequences.

🔗 (https://github.com/ravikantsharma06/python_basicsf_25BCON2154.git)

### 3. Project 3 — Structure

Learn the basic structure of a Python program, including statements, variables, input/output, and program flow.

**Concepts Covered:** Python syntax, variables, input/output, and program organization.

🔗 https://github.com/ravikantsharma06/python_basicss_25BCON2154.git

## 🎯 Learning Objectives

- Understand fundamental Python programming concepts.
- Improve logical thinking and problem-solving skills.
- Practice loops, variables, and conditional statements.
- Learn how to organize and structure Python programs.
- Build a foundation for more advanced Python projects.
